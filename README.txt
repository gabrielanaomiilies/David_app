MAREA AVENTURĂ A CHIVOTULUI – aplicație offline

1. Dezarhivează folderul într-o locație de pe calculator.
2. Deschide index.html cu Chrome, Edge sau Firefox.
3. Nu este necesară instalarea unui program și nu este necesară conexiunea la internet.

STRUCTURĂ
- index.html: paginile și conținutul aplicației
- style.css: designul și adaptarea pentru telefon/tabletă
- script.js: navigare, întrebări, punctaj și distribuirea rolurilor
- data.json: rezumat structurat al informațiilor și referințelor
- assets/: ilustrații și două diagrame SVG explicative cu săgeți (Chivotul și purtarea de către leviți)

NOTĂ DESPRE IMAGINI
Imaginile din assets sunt decupaje din ilustrațiile generate pentru această lecție. Sunt reconstituiri artistice, nu fotografii istorice sau descoperiri arheologice. Harta este o schemă didactică, nu o hartă topografică a unui traseu antic demonstrat.

NOTĂ BIBLICĂ
Aplicația diferențiază masa cu pâinile pentru punerea înainte (obiect separat din Cort) de Chivot. De asemenea, nu inventează o poziție exactă pentru casa lui Obed-Edom sau pentru aria lui Nacon/Chidon, deoarece textul biblic nu permite localizarea sigură.

DIAGRAME EXPLICATIVE
- chivot-diagrama-explicativa.svg: săgeți către cufăr, aur, capac, heruvimi, verigi și drugi.
- levitii-diagrama-explicativa.svg: arată pregătirea obiectelor de către preoți și transportul de către chehatiți.
Ambele diagrame pot fi apăsate pentru vizualizare mărită.
